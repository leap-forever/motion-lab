这一层为什么是纯静态 HTML

原站把站点分成两层：内容页（首页、游戏介绍、指南、文章，共 249 个 URL、11 种语言）是构建时预生成的静态 HTML，专门给搜索引擎和 AI 读，几乎不加载 JS；应用页（/start、/check、/play/*）才是由 Vite 打包的 React PWA。

本项目的 content/index.html 就是前一层的缩小版：上面两段 JSON-LD、speculationrules 预取、卡片图片全部是写死在 HTML 里的，服务端直接读文件返回，不经过 Service Worker。点击「打开应用」才进入后一层。

好处：内容页首屏极快、可被完整索引；应用页独立发版、可以整包预缓存做离线。代价是两套页面要各自维护导航与多语言。

隐私

摄像头画面只进入本机 <video> 与 canvas，audio:false；姿态识别在浏览器 WASM 中完成。服务端只保存成绩数字、昵称与星级，不接收图像。
